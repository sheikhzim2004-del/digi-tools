# Digi Tools

A modern and responsive product showcase website built with React and Tailwind CSS. Users can explore different digital products, add products to the cart, manage cart items, and proceed to checkout with a smooth user experience.

## 🚀 Live Site

[Live Link Here](https://digi-tools-nine.vercel.app/)

## 📂 GitHub Repository

[GitHub Repository Link Here](https://github.com/sheikhzim2004-del/digi-tools)

## 🛠️ Technologies Used

- React.js
- Tailwind CSS
- DaisyUI
- JavaScript (ES6+)
- React Toastify
- JSON Data

## ✨ Features

- Responsive product showcase with modern UI design
- Add, remove, and manage products in the shopping cart
- Dynamic cart count and checkout functionality with toast notifications

## 📌 Project Overview

Digi Tools is a digital product marketplace where users can browse available tools, view product details, and add their favorite products to the cart. The project focuses on responsive design, clean component structure, and interactive user experience.
